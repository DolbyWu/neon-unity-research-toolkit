# Three research targets (experimental)

Import this sample through Package Manager in a disposable project. Choose **Tools > GazeFlow > Create Three-Target Demo** to create three cubes with unique IDs in front of Main Camera (or world origin if absent). No recording or simulated eye stream starts. Use Undo to remove the demo.

Follow the [experimental integration guide](../../Documentation~/neon-xr-targets.md) to install the optional adapter, configure official calibration, the actual XR head Transform, and exactly one target recorder. Confirm mapping only after a known-target test. The sample is independent of any existing experiment and does not modify it automatically.
