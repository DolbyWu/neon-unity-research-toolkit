# Research recording test project

This minimal Unity 6000.3.23f1 project loads the sibling Neon Research package and Unity registry dependencies. Use it for installation checks and anonymous practice sessions, not formal participant collection.

Follow the repository's Quick Start. Open Tools → Neon Research → Setup and Recording Settings, choose a fresh output folder, enable Record on Unity Play and leave Neon/media off for the first test. Save, open the live monitor, press Play and confirm a test participant. Mark observations and Stop normally; inspect the session folder and HTML.

No headset setup, completed experiment, automatic interaction wiring or fabricated eye stream is included.
