# Tutorial screenshot provenance

User-supplied Unity Editor screenshots, prepared for the illustrated quickstart on 2026-11-15.

- `open-research-settings.png`: original project-specific window title cropped away. Other project menu entries remain as context, not package features.
- `recording-settings-redacted.png`: local network address, study condition and local output/executable/settings paths replaced with explicit placeholders/example paths.
- `live-monitor-redacted.png`: real eye/pupil traces, sample counts, recording duration, event rows, participant/session identifiers and local archive path removed or replaced with labelled interface examples. No synthetic trace was substituted for real data.
- `desktop-gaze-adjustment.png` and `live-observation-marker.png`: idle interface screenshots; bright controls remain locked until their normal workflow requirements are met.

All five public PNGs were re-encoded without source metadata. Original screenshots were not modified. These figures illustrate UI locations and do not constitute research records, accuracy evidence, default opt-in settings or a fresh hardware acceptance test.
